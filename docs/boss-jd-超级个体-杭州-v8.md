# Boss 直聘岗位描述 · 超级个体 _ 杭州 · v8

> 复制到 Boss 直聘后台「职位描述」。建议薪资：**8–12K（面议）**。

---

## 我们在做什么

开派智能科技，AI 初创。目前 2 人，产品方向是企业级 AI Agent 工具链。
不是外包公司，不是大厂螺丝钉。你来就是核心成员，直接参与从 0 到 1。

---

## 我们找什么人

**AI 原生开发者**——天然把 AI 工具融入工作流的人，不是传统程序员学了点 AI。

具体来说：
- 你试过**多种 AI 工具**（不止 ChatGPT + Cursor），知道哪个适合规划、哪个适合写码、哪个适合 Review
- 你有自己的 **workflow**——比如：需求拆解用 A → 架构设计用 B → 写代码用 C → 测试/Review 换 D
- 你有**能展示的东西**：上线产品、demo、开源仓库、小程序、作品集（不是课程大作业）
- 你能**自己 push 项目**，不是等人分配任务

**学历不卡。** 看你做过什么、怎么做的。

---

## 加分项

- 了解 Agent / MCP / RAG / 工具链编排等概念，有实践更好
- 近半年有明确的技术转型或学新栈的痕迹（比如从传统开发转 AI 工具链）
- 打招呼时说清楚你做过什么、怎么用 AI、为什么 fit——我们真的很看这个
- 有自发项目（副业/开源/个人产品），哪怕很小

---

## 不适合

- AI 只用来聊天/搜索/翻译，没拿它写过代码或做过产品
- 简历全是「熟悉 ChatGPT / 用过 Copilot」但零项目细节
- 一年换三份工作以上
- 完全不做技术，只想做管理/运营

---

## 薪资与工作方式

8–12K，能力特别匹配可谈。杭州线下。
不打卡，但要能自驱推进。每周有进度产出就行。

---

## 怎么投更容易被看到

打招呼时别只发「您好，请问还在招吗」。
两三句话介绍：**你做过什么项目 → 平时怎么用 AI 工具 → 为什么觉得 fit 这个岗**。
我们就靠这个 + 在线简历筛人，认真写的人会被优先看。
